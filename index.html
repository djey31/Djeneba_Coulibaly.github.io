Classification de variétés de haricots — Supervised Learning

Janvier 2026 — Projet académique AMSE

Classification supervisée automatisant l'identification de 7 variétés de haricots secs (13 543 observations, 16 descripteurs morphologiques).

  • Pipeline : EDA → RobustScaler → SMOTE → cross-validation stratifiée (5-fold)
  • Modèles testés : Logistic Regression, Elastic Net, SVM (RBF), MLP
  • Résultat : SVM (RBF) — Macro-F1 = 0.9369, Balanced Accuracy = 0.9357
  • Insight : la réduction PCA peut dégrader la séparabilité malgré une variance expliquée élevée
Python scikit-learn SVM SMOTE PCA
